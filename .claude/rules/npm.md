# Установка зависимостей

- `npm install` — только из корня репозитория и с явным `-w apps/<name>` (или `-D` для корня). Никаких `cd ... && npm install`: ошибка в цепочке уводит установку в чужую директорию.
- После установки проверить `git diff` по `package.json`: зависимость на месте, а соседние не пропали.
- Каждая новая зависимость — с причиной в `docs/DEVLOG.md`.
- Проверяется: `scripts/check-invariants.sh` (п. 5: каждый импортируемый пакет объявлен в `package.json`).
