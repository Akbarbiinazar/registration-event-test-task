# Сервис регистрации на мероприятия

Локальный демонстрационный сервис: создание события, регистрация участников,
билеты по почте, лист ожидания, чекин и live-статистика организатора.

## Запуск

Нужны Node.js 22+ и Docker Compose.

```sh
npm run db:up
npm run migrate
REMINDER_TICK_MS=10000 npm run dev
```

Web: <http://localhost:5173>. Почта Mailpit: <http://localhost:8025>.
Обычный интервал напоминаний — 60 секунд; команда выше задаёт 10 секунд для
демо. Первый тик выполняется при запуске API.

## Демо напоминания за ≤10 секунд

1. Создайте событие примерно через два часа и зарегистрируйте подтверждённого
   участника.
2. В течение следующих 10 секунд откройте Mailpit и найдите письмо
   «Напоминание о событии». Дата и время письма указаны в часовом поясе события.

Тик сразу при запуске может произойти до регистрации. Следующий тик будет не
позже чем через 10 секунд; отправщик почты проверяет outbox каждую секунду.

## Напоминания и доставка почты

Планировщик ставит напоминание каждому подтверждённому участнику в окне от
24 часов до начала события до самого начала. Границы: ровно за 24 часа —
включено, в момент начала — исключено. Поздно зарегистрированный участник и
участник, повышенный из листа ожидания, получают напоминание на следующем тике,
если событие ещё не началось. Ожидающий получает его только после повышения.
После переноса старое напоминание помечается пропущенным при захвате отправщиком;
для новой даты ставится новое с новой `schedule_version`.

Доставка **at-least-once**: ошибка отправки оставляет письмо в outbox для повтора
с backoff. Если SMTP принял письмо, а процесс упал до сохранения `sent_at`, при
повторе возможен дубль. Детерминированный `Message-ID` помогает почтовому
клиенту распознать его. Уникальный `dedup_key` гарантирует одно напоминание в
очереди на участника и версию даты.
