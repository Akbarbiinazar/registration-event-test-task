- Решения и почему:
  - Гарантии «одно место на email», «не больше лимита», «чекин один раз»,
    «одно напоминание» держит Postgres (частичный UNIQUE, условный UPDATE +
    CHECK, UNIQUE ключ дедупликации писем), а не код приложения.
  - Письма через outbox в той же транзакции — письмо не теряется и не
    уходит при откате.
  - Live через `pg_notify` → SSE: уведомление только после COMMIT, работает
    между соединениями и вкладками.
  - Без ORM: ключевые гарантии — это конкретный SQL, его надо видеть.
- Статус: ждёт подтверждения пользователя (допущения, дедлайн).
