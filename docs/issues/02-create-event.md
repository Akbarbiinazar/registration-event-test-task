# 02. Создание и просмотр события

**Цель:** организатор создаёт событие и получает секретную ссылку; любой видит
публичную страницу события.

**Зависит от:** 01  **Оценка:** 1 ч

## Объём
- Миграция `events` (см. `project_spec.md` §4, включая
  `CHECK (seats_taken BETWEEN 0 AND capacity)`, `schedule_version` и
  `timezone`).
- `POST /api/events` → `{ event, organizerKey }`; в БД — SHA-256 ключа. Тело
  содержит `timezone` (IANA, из `Intl.DateTimeFormat().resolvedOptions()` в
  браузере организатора); сервер проверяет его через `Intl`, невалидный →
  `400` (A13).
- `formatInZone(at, timezone)` — время в поясе события с подписью зоны
  («18:00 (Москва, UTC+3)»); им пользуются UI и шаблоны писем.
- `GET /api/events` — предстоящие (по `clock.now()`), `GET /api/events/:id` —
  публичные поля + `seatsLeft`.
- Аутентификация организатора: `Authorization: Bearer <key>`, сравнение хэшей
  через `timingSafeEqual`. `GET /api/organizer/events/:id` → событие + статистика
  (`registered`, `waitlisted`, `checkedIn`, `capacity`) — пока нули.
- UI: `/` список + кнопка «Создать»; `/events/new` форма; после создания —
  экран с публичной ссылкой и ссылкой организатора (`/o/:id#key=…`,
  «сохраните, больше не покажем»); `/e/:id` публичная страница (дата в поясе
  события, после начала — метка «Событие уже идёт», A11); `/o/:id` страница
  организатора (ключ читается из `#fragment`).

## Не входит
Регистрация, редактирование события.

## Критерии приёмки
- [ ] Создать событие в UI → открыть публичную и организаторскую ссылки в
      разных вкладках.
- [ ] Валидация: пустое название, лимит 0, дата в прошлом → 400 с понятной
      ошибкой в UI.
- [ ] Организаторский эндпоинт без ключа / с чужим ключом → 401.
- [ ] Время события на публичной и организаторской страницах — в поясе
      события с подписью зоны, совпадает с введённым.

## Тесты
- создание и чтение события; валидация; 401 без/с неверным ключом;
- ключ организатора не хранится в БД в открытом виде;
- невалидный `timezone` → 400; `format.test.ts`: `formatInZone` для двух поясов;
- `INSERT` с `capacity = 0` → `check_violation`.
