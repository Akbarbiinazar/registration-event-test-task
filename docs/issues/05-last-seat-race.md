# 05. Гонка за последнее место

**Цель:** доказать, что при одновременной регистрации на последнее место оно
достаётся одному, а остальные попадают в лист ожидания; и что параллельные
отказы не ломают повышение.

**Зависит от:** 04  **Оценка:** 0.5 ч  **Доказывает:** P3

## Объём
- Тестовый хелпер для настоящей конкурентности: пул на ≥ 25 соединений,
  старт через общий «барьер» + `Promise.all`.
- Тесты из P3 и параллельные отказы из P2 (вспомогательные).
- Если тесты найдут гонку — исправление в домене с записью в DEVLOG, что
  именно было не так.

## Не входит
Новый функционал и UI.

## Критерии приёмки
- [ ] P3 зелёный стабильно: `npm run test:proofs` 5 раз подряд без падений
      (вывод в DEVLOG).
- [ ] Прямой `UPDATE` сверх лимита → `check_violation`.

## Тесты
- **P3** (`proofs/p3-last-seat-race.proof.test.ts`): 20 параллельных × 10
  раундов; кейс «ровно двое»;
- 2 параллельных отказа при 2 ожидающих → оба повышены по одному разу;
- **регистрация в лист ‖ отказ при пустом листе (D1):** 50 раундов → C всегда
  `confirmed`, лист пуст. Проверяет, что регистрация берёт `FOR UPDATE` на
  событие: без него C остаётся в листе при свободном месте;
- параллельно: отказ подтверждённого + новая регистрация при непустом листе →
  место уходит первому из листа, новый — в конец очереди.
