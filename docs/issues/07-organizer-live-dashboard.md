# 07. Live-экран организатора

**Цель:** организатор видит «зарегистрировано / в листе ожидания / пришло», и
цифры меняются без перезагрузки во всех открытых вкладках.

**Зависит от:** 06  **Оценка:** 1.5 ч  **Доказывает:** P5

## Объём
- `live/notifier.ts`: выделенный `pg.Client`, `LISTEN event_stats`,
  переподключение с backoff и повторным `LISTEN`; подписчики по `eventId`.
- `GET /api/organizer/events/:id/stream?key=…` (SSE; ключ в query — у
  `EventSource` нет заголовков): сразу снимок статистики, далее снимок после
  каждого NOTIFY по событию; heartbeat-комментарий каждые 15 с; отписка при
  закрытии соединения.
- Статистика одним запросом: `count(*) FILTER (WHERE …)`.
- UI `/o/:id`: три крупные цифры + «мест осталось», индикатор соединения
  («live» / «переподключение…»), ссылка на экран чекина.

## Не входит
Список участников (можно, если останется время в 11 — не обещаем).

## Критерии приёмки
- [x] Две вкладки `/o/:id` + третья с чекином: после чекина обе вкладки
      показывают «пришло: 1» без перезагрузки.
- [x] Регистрация на публичной странице меняет «зарегистрировано» live.
- [x] Перезапуск API → вкладка показывает «переподключение…», затем снова live
      с актуальными цифрами.
- [x] P5 зелёный.

## Тесты
- **P5** (`proofs/p5-checkin-live.proof.test.ts`): настоящий HTTP-сервер,
  два SSE-потока;
- изменение через другое соединение БД доходит до SSE;
- SSE без ключа → 401.
