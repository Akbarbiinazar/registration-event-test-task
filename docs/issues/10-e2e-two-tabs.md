# 10. E2E: две вкладки

**Цель:** показать требование 11 («работает при двух открытых клиентах») в
настоящем браузере.

**Зависит от:** 07  **Оценка:** 1 ч

## Объём
- Playwright (Chromium), `npm run test:e2e`; `webServer` поднимает api и web
  против базы `events_test`.
- Сценарий: создать событие (лимит 1) через UI → контекст A: экран
  организатора; контекст B: регистрация двух участников (второй в листе
  ожидания) → A видит «1 / 1 в листе» без перезагрузки → контекст B: чекин
  кода (код берётся из API Mailpit или из БД теста) → A видит «пришло: 1».
- Скриншоты/trace при падении.
- В CI — отдельным job, если укладывается по времени.

## Критерии приёмки
- [ ] `npm run test:e2e` зелёный локально.

## Если не хватает времени
Режется первым (очередь отсечения 1): ручной сценарий в README.
