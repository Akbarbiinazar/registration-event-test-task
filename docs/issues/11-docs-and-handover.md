# 11. Документация и сдача

**Цель:** закрыть пункты «Что мы ожидаем от вас» и требования 8, 9, 12, 13.

**Зависит от:** все  **Оценка:** 1 ч

## Объём
- `README.md`:
  - что это и ссылки на спецификацию/план доказательств;
  - предварительные требования (Docker, Node ≥ 22, свободные порты);
  - запуск за 3–4 команды; адреса (web, Mailpit);
  - ручной демо-сценарий (две вкладки, письма, чекин, перенос, как
    «перемотать» время для напоминания — через `REMINDER_TICK_MS` и событие
    через ≤ 24 ч);
  - **состояние проекта:** таблица «работает / не работает / не делали и
    почему» — по фактам, со ссылками на тесты;
  - чем делали: модель, инструмент, почему (пара предложений);
  - что сделали бы следующим заходом;
  - шаблоны/генераторы, взятые за основу (Vite template и т.п.).
- `docs/DEVLOG.md` — финальная запись, общий таймлайн (начало → конец).
- Экспорт сессий агента в `docs/agent-sessions/` (если решите отдавать) или
  ссылка на DEVLOG.
- Финальный прогон: `npm run check` + `npm run test:e2e` + `scripts/smoke.sh`,
  вывод в DEVLOG.
- Проверка «с нуля»: свежий клон → инструкция README → работает.

## Критерии приёмки
- [ ] Свежий клон запускается строго по README.
- [ ] Каждое утверждение «работает» в README подкреплено тестом или
      шагом ручной проверки.
